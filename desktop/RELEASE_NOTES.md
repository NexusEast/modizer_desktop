Mac desktop update on top of 4.6.2 (Mac Catalyst, Apple Silicon).

## New
- Duty swap toggle in the Voices panel while playing NSF/NSFE
- Swaps NES pulse duty 25% and 50% (Dendy / famiclone APU)
- Applies live for NSFPlay and GME without reloading the file

## Requirements
- Apple Silicon Mac (arm64)
- macOS that can run Mac Catalyst apps targeting iOS 15.5+

## Install
1. Open the DMG and drag **Modizer** to Applications.
2. This build is signed with Developer ID and notarized.

Official iOS Modizer remains [yoyofr/modizer](https://github.com/yoyofr/modizer).
